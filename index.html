How to Turn This Into an Android APK

This web app is 100% PWA-configured and comes with full Capacitor and Web Manifest integration. You can generate an .apk file in two simple ways:

Method 1

PWABuilder (Easiest — 2 Minutes, No Coding)

  1. Deploy this folder to any free host like Netlify, Vercel, or GitHub Pages.
  2. Visit PWABuilder.com and paste your URL.
  3. Click Package for Android and download your signed ready-to-install .apk!
Method 2

Capacitor CLI (Local Android Studio Build)

  1. Run in terminal: npm run cap:android (pre-configured in this project).
  2. Android Studio will open automatically.
  3. Click Build > Build Bundle(s) / APK(s) > Build APK(s).
  4. Your app-debug.apk is saved in android/app/build/outputs/apk/debug/. Transfer and install on any phone!
Direct Phone Install

Instant Mobile App Without Building APK

Open the website in Chrome on your Android phone, tap ⋮ (Menu) > Add to Home screen (or "Install app"). It installs as a full standalone app with icon, offline cache, and full-screen experience!
